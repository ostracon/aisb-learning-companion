# Security policy

AISB Learning Companion is a localhost application that can read a curriculum
checkout, save learner notes, and start restricted Codex sessions. Reports
about path boundaries, source disclosure, prompt-context isolation, unsafe
process launch, note loss, credential exposure, or same-origin protections are
especially useful.

Please use GitHub's **Security → Report a vulnerability** flow for sensitive
reports. Do not open a public issue containing an exploit, credential, learner
data, private schedule data, or an absolute path from your machine.

Include the affected commit, operating-system and Node versions, a minimal
redacted reproduction, and the impact. Replace personal paths, tokens, note
contents, and repository-specific private data with synthetic placeholders.

Ordinary bugs and feature requests can use the public issue tracker.
