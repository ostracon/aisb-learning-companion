# Warm field notebook reference

`warm-field-notebook.png` is the user-selected visual direction for the AISB Learning Companion, chosen on 2026-08-29 from two exploratory mood previews.

Treat the image as a composition and mood reference, not a pixel-perfect specification. Its normative qualities are:

- warm ivory paper-like surfaces with near-black ink;
- a restrained cobalt accent for orientation and primary actions;
- modest editorial serif headings paired with a readable humanist sans-serif body;
- a slim week/day rail, notes-led central workspace, and quiet tutor inspector;
- hairline dividers, disciplined whitespace, minimal elevation, and very little ornamental chrome.

The example dates, schedule labels, learning outcomes, note text, chat messages, controls, and exact dimensions are illustrative placeholders. Product content comes from the local schedule, AISB curriculum, notes, and Codex threads. The implementation must also add the planned “Sync to now” control and its frozen programme-time status. The sidebar, schedule, and tutor/chat must each collapse independently, with a reversible “Focus notes” mode that collapses all three and expands the editor. Those later requirements are not depicted in the reference image.
